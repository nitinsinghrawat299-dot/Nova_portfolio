# NOVA Portfolio — Simple & Bold

A simple, bold, responsive portfolio for Nitin Rawat and NOVA.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. No installation or build command is required.

## Deploy on Vercel
1. Upload the contents of this folder to a GitHub repository.
2. Import that repository into Vercel.
3. Choose **Other** as the framework if asked.
4. Deploy as a static site; no build command is required.

## Customize
- Text and project links: `index.html`
- Colors and layout: `assets/style.css`
- Mobile menu: `assets/script.js`
