# Nova — Nitin Rawat Portfolio

A responsive, scrolling portfolio for Nitin Rawat, founder of Nova. Built with plain HTML, CSS, and JavaScript so it can be deployed to Vercel's free tier without a build step.

## Included
- Animated scroll reveals and marquee
- Responsive mobile navigation
- Real screenshots from Nova CafeLedger and Snap Pin Report
- Direct links to both live prototypes
- Contact links for email and phone
- Reduced-motion support and accessible image descriptions

## Run locally
Open `index.html` in a browser, or run a local static server from this folder. For example:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Deploy to Vercel (free)
1. Extract this ZIP.
2. Create a new GitHub repository and upload the contents of the `nova-portfolio` folder (the `index.html` file should be at the repository root).
3. Sign in to Vercel and choose **Add New → Project**.
4. Import that GitHub repository.
5. For Framework Preset, choose **Other**. Leave Build Command and Output Directory empty/default; this is a static site.
6. Click **Deploy**. Vercel will provide a public `*.vercel.app` address.

You can also deploy the folder using Vercel CLI if you have Node.js installed. The project does not require a paid plan or a custom domain.

## Personalize
- Edit the intro and project copy in `index.html`.
- Replace or update screenshots in `public/images/` and adjust the image paths in `index.html` if filenames change.
- The abstract Nova artwork is decorative concept art, not a company logo or portrait.
