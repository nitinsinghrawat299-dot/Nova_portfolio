# NOVA Portfolio

Simple one-page portfolio for Nitin Rawat / NOVA.

## Add your real screenshots (important)
Put two full-page screenshots in `assets/shots/`:
- `cafeledger.png`
- `cleancity.png`

See `assets/shots/README.txt` for how to take them. Until they exist, a simple placeholder is shown.

## Preview
Open `index.html` in a browser. No build step.

## Deploy on Vercel
Upload this folder to GitHub, import it in Vercel, choose "Other", deploy.

## Edit
- Text and links: `index.html`
- Colors and layout: `assets/style.css`
- Scroll animation: `assets/script.js`
