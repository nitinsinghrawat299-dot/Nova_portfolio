# Nova Portfolio — Nitin Rawat

A responsive, one-page portfolio for **NOVA**, Nitin Rawat's AI-powered web and automation studio.

## What's included

- `index.html` — the complete scrollable portfolio
- `assets/style.css` — responsive dark theme, project mockups, and layouts
- `assets/script.js` — mobile navigation, email copy interaction, and subtle reveal effects

## Run locally

1. Download and unzip `nova-portfolio.zip`.
2. Open the `nova-portfolio` folder.
3. Double-click `index.html` to open it in your browser.

No package installation or build step is needed. An internet connection is used for Google Fonts; system fallback fonts work without it.

## Deploy free on Vercel

1. Create a new GitHub repository and upload the files inside this folder (the `index.html` file should be at the repository root).
2. Sign in to Vercel and choose **Add New → Project**.
3. Import the GitHub repository.
4. For a static HTML site, leave the framework preset as **Other**. No build command is needed; use `.` as the output directory if Vercel asks for one.
5. Deploy. Vercel will provide a public URL.

You can also host the files on any static hosting service.

## Customize

- Edit the content in `index.html`.
- Change colors near the top of `assets/style.css` in the `:root` section.
- Replace project links in `index.html` when you add more projects.
- Contact email is currently `nitinrawat2811@gmail.com`.
- The project visuals are CSS-built mockups, not screenshots of the live apps.
- The email contact action opens the visitor's email app; no form backend is configured.
